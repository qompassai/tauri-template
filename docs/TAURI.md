# Tauri quickstart

Tauri: https://tauri.app/ — secure cross-platform apps with a
Rust backend and web frontend.

- Scaffold: `npm create tauri-app@latest`
- Dev: `npm run tauri dev`; build: `npm run tauri build`
- Capabilities (v2 ACL) live in `src-tauri/capabilities/` —
  least privilege by default.
